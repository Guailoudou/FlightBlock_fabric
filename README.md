# FlightBlock

适用于 Minecraft Java Edition 26.3 / Fabric 的限时飞行方块 Mod。合成飞行标靶、放置并右键激活后，即可在指定范围内飞行。

支持单人世界和专用服务器。专用服务器安装后，玩家可以使用原版客户端连接。

## 功能

- 三个等级，可分别配置使用时长和飞行半径。
- 每个方块同时最多绑定一名玩家；一名玩家可以绑定多个方块。
- 右键已占用方块时显示当前使用者的名字和方块剩余时间。
- 激活后显示与等级一致的发光轮廓：一级金色、二级青色、三级紫色；物品栏上方显示剩余距离和倒计时。
- 蹲下右键解除当前方块的绑定，释放占用。
- 离开有效范围时撤销飞行，空中给予缓降。
- 保存方块的激活时间和到期时间，重新进入世界不会重置期限。

| 等级 | 默认时长 | 默认半径 |
| --- | --- | --- |
| I | 5 分钟 | 64 格 |
| II | 15 分钟 | 128 格 |
| III | 6 小时 | 256 格 |

范围以方块中心为球心，包含边界，水平和垂直距离均参与计算。

## 下载

通过仓库的 GitHub Actions 获取构建产物：

1. 打开 **Actions → Build FlightBlock**。
2. 选择一次成功的运行。
3. 在 **Artifacts** 中下载 `flightblock-<运行编号>` 并解压。
4. 取出 `flightblock-<版本>.jar`，作为安装包使用。

下载产物包含安装 JAR 和对应的 `SHA256SUMS` 校验文件，保留 30 天。下载时需要登录 GitHub。`-sources.jar` 是源码包，不用于安装。

仓库包含 [构建工作流](.github/workflows/build.yml)，push 和 pull request 会自动构建，也可通过 **Run workflow** 手动触发。Fork 后如 Actions 未启用，先在仓库的 Actions 页面启用工作流。

## 安装

本项目的构建环境：

| 依赖 | 版本 |
| --- | --- |
| Minecraft Java Edition | 26.3 |
| Fabric Loader | 0.19.5 |
| Fabric API | 0.161.0+26.3 |
| Java | 25 |

### 单人世界

1. 安装对应版本的 Fabric 游戏实例。
2. 关闭游戏，将 FlightBlock 安装 JAR 和 Fabric API 放入该实例的 `mods` 目录。
3. 启动游戏并进入世界。

升级时请移除旧版 FlightBlock JAR，避免同时加载多个版本。使用隔离实例的启动器时，以该实例目录为准。

### 专用服务器

将 FlightBlock 安装 JAR 和 Fabric API 放入 Fabric 服务器的 `mods` 目录，然后启动服务器。客户端无需安装 FlightBlock 或专用资源包，可使用相同 Minecraft 版本的原版客户端连接。

## 使用

1. 在 3×3 工作台中合成飞行方块。
2. 放置方块。此时尚未开始计时。
3. 普通右键激活并绑定，再双击跳跃起飞。
4. 蹲下右键解除自己对当前方块的绑定，或使用 `/flightblock off` 解除全部绑定。

首次激活开始计时；重复右键、解绑后重新绑定或其他玩家接替使用，都不会刷新到期时间。已被占用的方块会拒绝其他玩家绑定。

右键已被占用的方块时，会提示“该飞行方块正由 玩家名 使用，剩余 N 秒”。名字按当前在线玩家信息读取；使用者解绑、死亡或离线后释放占用，下一位玩家绑定后提示随之更新。

聊天提示带青色 `[FlightBlock]` 前缀，玩家名字以黄色加粗显示，剩余时间和半径以金色突出；成功消息为绿色，提醒为黄色，错误为红色。

离开全部有效范围时会撤销飞行，但保留绑定和占用，返回未到期范围后恢复资格。死亡、退出世界、掉线或跨维度会清空该玩家的绑定并释放占用，之后需要重新右键。方块被挖走、替换或到期也会释放对应占用。

已绑定多个方块时，飞行范围取并集。状态栏显示同维度有效绑定中距离余量最大的方块，并显示该方块的剩余时间；超出全部范围时显示红色提示。

期限按现实时间计算，暂停、离线和停服期间仍计时。到期后方块消失且不掉落；在卸载区块中到期的方块会在区块重新加载后处理。

生存模式挖掘会返回保留原期限的物品，重新放置后需重新右键。已激活物品不能升级。创造拆除和爆炸不返回物品，飞行方块不能被活塞推动。

## 合成配方

仅支持 **3×3 工作台手动合成**，每次产出一个飞行方块。配方书不显示这些配方，自动合成器不支持。

### I 级

| | | |
| --- | --- | --- |
| 羽毛 | 金锭 | 羽毛 |
| 金锭 | 普通标靶 | 金锭 |
| 羽毛 | 金锭 | 羽毛 |

### II 级

| | | |
| --- | --- | --- |
| 羽毛 | 钻石 | 羽毛 |
| 钻石 | 未激活 I 级飞行方块 | 钻石 |
| 羽毛 | 钻石 | 羽毛 |

### III 级

| | | |
| --- | --- | --- |
| 钻石 | 下界之星 | 钻石 |
| 下界之星 | 未激活 II 级飞行方块 | 下界之星 |
| 钻石 | 下界合金锭 | 钻石 |

升级材料必须是**从未右键激活**的上一级飞行方块。普通标靶或仅被改名的物品不能替代升级材料。

## 配置

首次启动时在游戏实例或服务器目录生成 `config/flightblock.json`。默认配置也可查看 [示例文件](config/flightblock.json)。

```json
{
  "configVersion": 1,
  "durationsSeconds": {"1": 300, "2": 900, "3": 21600},
  "radiiBlocks": {"1": 64, "2": 128, "3": 256},
  "flightCheckIntervalTicks": 5,
  "slowFallingSeconds": 10,
  "displayTimeZone": "Asia/Shanghai"
}
```

| 字段 | 含义 | 允许值 |
| --- | --- | --- |
| `configVersion` | 配置版本 | `1` |
| `durationsSeconds` | 各等级首次激活后的时长，单位秒 | 每级为 1～31536000 的整数 |
| `radiiBlocks` | 各等级飞行半径，单位格 | 每级为 1～4096 的整数 |
| `flightCheckIntervalTicks` | 飞行资格及状态栏检查周期 | 1～20 tick |
| `slowFallingSeconds` | 空中失去飞行权限后的缓降时长 | 0～60 秒；`0` 表示关闭 |
| `displayTimeZone` | 物品到期时间的显示时区 | 合法 Java 时区，如 `Asia/Shanghai`、`UTC` |

时长和半径配置必须分别包含 `1`、`2`、`3` 三个等级。旧配置完全没有 `radiiBlocks` 时使用默认半径；需要自定义时补上该字段。

保存后执行 `/flightblock reload`，无需重启。新半径立即影响已激活方块；新时长仅用于之后首次激活的方块，**已有到期时间保持不变**。升级 Mod 不会自动覆盖已有配置中的时长。

重载遇到非法配置会保留旧设置，并反馈错误。普通 `/reload` 不会重载本 Mod 的配置。

## 指令

| 指令 | 功能 | 权限 |
| --- | --- | --- |
| `/flightblock give <players> <level> [count]` | 发放飞行方块；等级 1～3，数量 1～64，默认 1 | OP 等级 2 或控制台 |
| `/flightblock reload` | 重载配置 | OP 等级 2 或控制台 |
| `/flightblock status` | 查看自己的绑定、坐标、半径和剩余时间 | 所有玩家 |
| `/flightblock off` | 解除自己的全部绑定并释放占用 | 所有玩家 |

例如 `/flightblock give @s 1` 可获得一个一级方块。单人世界中，管理员指令需要开启作弊。控制台使用指令时省略开头的 `/`。

## 从源码构建

安装 JDK 25，并将 `JAVA_HOME` 指向该 JDK。在仓库根目录执行：

**Windows：**

```powershell
.\gradlew.bat --no-daemon clean build
```

**Linux / macOS：**

```bash
chmod +x gradlew
./gradlew --no-daemon clean build
```

安装 JAR 输出到 `build/libs/`。Gradle Wrapper 会下载所需 Gradle 版本，构建会自动执行规则和配方回归检查；这些检查不启动 Minecraft 世界。

## 兼容说明与问题反馈

发光轮廓是视觉效果，不会照亮周围环境。状态栏可能被其他 Mod 的提示覆盖；修改飞行权限的其他 Mod 也可能产生兼容问题。

反馈问题时，请提交 Minecraft、Fabric Loader、Fabric API 和 FlightBlock 版本、复现步骤，以及游戏或服务器 `logs/latest.log` 中的相关异常。提交日志前请移除个人信息和敏感内容。
