## 加载器与权限

Fabric / Quilt 内嵌与目标 Minecraft 匹配的 Player Ability Lib，仍需单独安装对应 Fabric API。Quilt 使用 Fabric 兼容接口。

Forge / NeoForge 使用各自的生命周期和玩家交互事件，以及独立的飞行权限适配。撤销 FlightBlock 授权时保留授予前已有的飞行资格；与其他直接修改玩家能力的 Mod 同时使用时，需要在实际游戏中检查兼容性。1.20.1 NeoForge 使用该版本发行版的 `net.minecraftforge` 接口。

各版本适配物品 NBT／组件、配方序列化、存档及事件 API。早期版本的发光轮廓使用隐形实体实现，玩家仍操作原版标靶。各版本保留三种配方、等级配置、单人及服务端模式、占用限制、死亡解绑、粒子和状态栏提示。

## 构建与下载

GitHub Actions 对每个组合独立执行 Gradle，不启动游戏或服务端。检查包括规则断言、Fabric / Quilt 的 PAL 授权隔离和配方标记检查，以及所有加载器的入口类、依赖、Mixin 配置、必要映射和安装 JAR 检查。

所有组合成功后，汇总任务发布一个可直接下载的 ZIP，包含 67 个 JAR 和 `SHA256SUMS`：

```text
FlightBlock-all-versions-<运行编号>.zip
├── 1.16.5/
│   ├── flightblock-1.16.5-fabric-0.2.0.jar
│   ├── flightblock-1.16.5-quilt-0.2.0.jar
│   └── flightblock-1.16.5-forge-0.2.0.jar
├── ...
├── 26.3/
│   ├── flightblock-26.3-fabric-0.2.0.jar
│   ├── flightblock-26.3-quilt-0.2.0.jar
│   ├── flightblock-26.3-forge-0.2.0.jar
│   └── flightblock-26.3-neoforge-0.2.0.jar
└── SHA256SUMS
```

任一组合失败都会阻止合集发布。成功发布后删除本轮临时的单目标产物，保留合集 30 天。只选择对应游戏版本和加载器的一个 JAR 安装。

编译工具使用的 JDK 与游戏运行的 Java 版本可以不同：Actions 使用现代 JDK 运行构建插件，为旧版本生成相应版本的字节码。1.16.5 安装包中的 Mod 和内嵌辅助代码会额外检查 Java 8 字节码版本。
